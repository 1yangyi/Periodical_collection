基于Transwell底膜的细胞间隧道纳米管三维共培养体系研究
尤钺, 杨家诚, 万楚琪, 李金霞, 郑奕婷, 赵峰
陕西师范大学学报(自然科学版). 2026, 54(6): 1-10.  https://doi.org/10.15983/j.cnki.jsnu.2026601
摘要 (   )  PDF全文 (   )   HTML (   )
针对传统共培养体系中隧道纳米管(tunneling nanotubes,TNT)观察存在的诸多限制,建立一种基于Transwell底膜(Transwell membrane,TM)的三维共培养系统,联合高分辨激光扫描共聚焦显微镜及三维重建技术,实现TNT的可视化观察、空间定位及结构特征分析,为后续功能研究提供可靠的工具与方法。在孔径为1.0 μm的聚碳酸酯或聚酯材质的Transwell上室(TM膜上侧)接种3T3-L1前体脂肪细胞并诱导其分化为成熟脂肪细胞,在TM下侧接种乳腺癌细胞MDA-MB-231,形成三维共培养体系。共培养后,采用免疫荧光染色法对TNT进行特异性标记,裁剪TM制备样品,利用激光共聚焦显微镜进行X、Y、Z轴连续扫描,并在Imaris软件中进行三维重构与图像渲染。结果发现,成熟脂肪细胞与MDA-MB-231细胞之间可以通过1.0 μm的膜孔形成TNT结构,且α-微管蛋白是TNT的主要组成成分之一。定量形态学分析显示,TNT的直径介于50~600 nm,长度最长可达5.5 μm。方向性分析表明,TNT明显由TM膜上方细胞向下方细胞延伸,提示重力方向可能影响其生长方向。此外,传统F-肌动蛋白染料(如罗丹明-鬼笔环肽)在TM膜上出现强烈非特异性结合,而免疫荧光染色则表现出良好的特异性和成像质量。上述结果说明,建立的基于TM底膜支持骨架和1.0 μm孔径的三维共培养系统能够有效支持TNT的形成和跨膜延伸,并可实现高分辨三维成像与空间定量分析,其克服了传统二维共培养模型的关键局限,为TNT介导的细胞间通讯研究提供了可重复、稳定、适用性强的技术平台。
基于生物条形码和末端延伸双重信号放大策略构建蛋白激酶电化学生物传感器
吴思盈, 杨金菊, 李富萍, 张艳丽, 王红斌, 杨文荣, 庞鹏飞
陕西师范大学学报(自然科学版). 2026, 54(6): 11-21.  https://doi.org/10.15983/j.cnki.jsnu.2026602
摘要 (   )  PDF全文 (   )   HTML (   )
结合生物条形码和末端延伸技术双重信号放大策略构建一种电化学生物传感器,用于蛋白激酶A(protein kinase A,PKA)活性分析。采用电沉积法在玻碳电极表面修饰金纳米粒子(AuNPs/GCE),进一步将半胱氨酸修饰底物肽链通过Au—S键自组装到AuNPs/GCE表面。当目标物PKA存在时,底物肽链发生磷酸化,生物条形码探针(S1-AuNPs-S2)通过Zr4+介导作用与磷酸化肽链连接,被修饰到电极表面。在末端脱氧核苷酸转移酶(terminal deoxynucleotidyl transferase, TdTase)的作用下,生物条形码探针S2链发生末端延伸扩增,扩增产物与生物素标记DNA S3(biotin-S3)发生杂交,再结合辣根过氧化物酶标记链霉亲和素(horseradish peroxidase labeled streptavidin, SA-HRP),在过氧化氢(H2O2)和氢醌(HQ)底液中产生放大的电化学响应信号,实现对PKA活性的定量分析。该电化学生物传感器检测PKA的线性范围为0.01~100 U/mL,检出限为0.005 U/mL。构建的电化学生物传感器具有良好的选择性和重现性,可成功用于细胞裂解液实际样品中PKA的活性测定,在PKA抑制剂筛选和激酶相关药物分析方面具有良好的应用前景。
光谱法比较PCN和PCN-AuPt与牛血清白蛋白的相互作用
韩菲菲, 彭思贝, 范丽梅, 刘馨蔓, 贾蕙语, 王海萍, 刘钰晨
陕西师范大学学报(自然科学版). 2026, 54(6): 22-31.  https://doi.org/10.15983/j.cnki.jsnu.2026603
摘要 (   )  PDF全文 (   )   HTML (   )
光敏剂作为光动力治疗(photodynamic therapy, PDT)的核心要素,其理化性质对PDT的治疗效果具有重要影响。研究运用荧光光谱法、紫外可见吸收光谱法和同步荧光光谱法,对比PCN和PCN-AuPt两种纳米光敏剂与牛血清白蛋白(bovine serum albumin, BSA)的相互作用,发现二者均能与BSA自发形成1∶1配合物,通过静态淬灭机制降低BSA荧光,并增强BSA微环境的疏水性。其中,PCN-AuPt与BSA的结合常数(Ka)和结合位点数均大于PCN,其结合主要由静电作用和疏水作用驱动,而PCN主要依赖静电作用与BSA结合。此外,药代动力学实验结果表明,PCN-AuPt在小鼠血液中代谢时间更长,这与其更强的蛋白结合特性相关。研究结果揭示AuPt纳米酶的原位还原掺杂显著增强了PCN与BSA的结合能力,为新型纳米光敏剂的表面修饰与性能优化提供了理论依据。
福白菊水提物抗高盐高脂饮食诱发的小鼠肝脏炎性损伤及机制研究
刘丹娜, 张尤嘉, 张红云, 蒲蕊, 王海萍, 侯晓莹
陕西师范大学学报(自然科学版). 2026, 54(6): 32-41.  https://doi.org/10.15983/j.cnki.jsnu.2026604
摘要 (   )  PDF全文 (   )   HTML (   )
为探究高盐高脂饮食对小鼠的肝脏损伤及福白菊水提物对其的治疗作用,通过高盐高脂饲料诱导小鼠肝脏炎性损伤,并采用福白菊水提物进行治疗。实验第3、6、9个月分别处死小鼠,通过脏器系数、血清生化指标、病理切片、网络药理学探究福白菊发挥治疗作用的潜在机制。结果表明,高盐高脂饮食可诱发肝脏炎性病理学改变,高盐高脂组小鼠肝脏谷丙转氨酶(alanine aminotransferase,ALT)、谷草转氨酶(aspartate aminotransferase,AST)、γ-谷氨酰基转移酶(γ-glutamyl transferase,γ-GT)水平显著升高,还原型谷胱甘肽(reduced glutathione,GSH)水平显著降低,而福白菊干预可显著回调由高盐高脂饮食诱导的肝脏血清指标紊乱,提示福白菊可有效缓解高盐高脂诱发的肝脏损伤。网络药理学结果显示,福白菊可通过咖啡酸、4,5-二咖啡酰奎宁酸、1,5-二咖啡酰奎宁酸、芹菜素、木犀草素等活性成分作用于EGFR、TNF、TP53等靶点,调节IL-17、Toll样受体等信号通路发挥抗肝炎作用。综上,高盐高脂饮食可引起小鼠肝脏炎性损伤,导致肝炎发生;福白菊水提物对高盐高脂饮食诱发的小鼠肝脏炎性损伤具有治疗作用,可考虑作为潜在肝脏炎性损伤防治的药食同源药物。
基于非靶向代谢组学的江西与重庆枳壳代谢物差异分析
况刚, 汪杨丽, 舒抒, 李雷, 陈祺, 张丽, 银福军, 高家敏
陕西师范大学学报(自然科学版). 2026, 54(6): 42-54.  https://doi.org/10.15983/j.cnki.jsnu.2026605
摘要 (   )  PDF全文 (   )   HTML (   )
为揭示江西、重庆2个代表性产区的枳壳代谢物组成及相对含量差异,基于超高效液相色谱-四极杆-飞行时间质谱联用技术(UPLC-Q-TOF-MS),采用非靶向代谢组学策略对2个产区枳壳样品进行系统分析。通过主成分分析与正交偏最小二乘判别分析进行多元统计建模,筛选出具有显著差异的代谢物,并结合KEGG数据库进行代谢通路注释与富集分析。结果显示,2个产区的枳壳样品中共检测到1 861种代谢物,涵盖17类化合物,从中鉴定出857个差异代谢物。在差异代谢物中,江西产区枳壳的维生素K3、绿原酸甲酯、柚皮芸香苷、川陈皮素等成分相对含量较高;而重庆产区枳壳的1, 4-萘醌、育亨宾、木犀草素等代谢物的含量更为丰富。KEGG通路分析显示,有103个差异代谢物涉及66条代谢通路,其中“黄酮和黄酮醇的生物合成”与“黄酮类化合物的生物合成”通路富集最为显著(p<0.05)。研究结果从代谢组学角度揭示了不同产区枳壳在化学成分上的差异性,为其质量评价、产区溯源及道地性研究提供了科学依据,也为枳壳功能成分的深入挖掘与开发利用提供了数据支持。
生态安全与治理修复
阿坝州干旱河谷生物多样性时空分布格局
潘俊君, 卫海燕
陕西师范大学学报(自然科学版). 2026, 54(6): 55-69.  https://doi.org/10.15983/j.cnki.jsnu.2026606
摘要 (   )  PDF全文 (   )   HTML (   )
县域尺度上生物多样性时空分布格局对制定和实施生物多样性保护措施具有重要意义。以阿坝州干旱河谷地区(汶川县、理县、茂县)为研究区,基于InVEST模型与遥感、GIS技术,选取香农多样性指数、生境质量指数、净初级生产力、归一化植被指数、表层水分含量和陆表温度6项指标作为评价标准,评估2010—2020年阿坝州干旱河谷生物多样性的时空分布特征。结果表明:6项评估指标整体呈“东高西低”的空间格局及波动中趋稳的演变特征。生物多样性指数亦表现出一致的空间特征,高值区主要集中在汶川县东部、理县西南部和北部及茂县南部和北部的林地,面积占比稳定在约10.50%;低值区分布于汶川县和理县西部的低覆盖度草地及人类活动强烈的河谷,面积呈先增加后稳定趋势,2015年后面积占比稳定在11.00%以上。2010—2020年生物多样性整体呈上升趋势,其中汶川县东南部与茂县东部提升显著,汶川县中部与茂县东南部退化明显,理县较为稳定。上述格局表明生态工程与人类干扰共同塑造了县域内显著的空间分异。基于此,结合生物多样性空间分异特征,并考虑县域管理的实际可行性,提出了相应的保护对策。
不同平茬模式对花棒根系构型的影响
郭月峰, 宋洋, 张志强, 祁伟, 冯雅洁, 王桂华
陕西师范大学学报(自然科学版). 2026, 54(6): 70-79.  https://doi.org/10.15983/j.cnki.jsnu.2026607
摘要 (   )  PDF全文 (   )   HTML (   )
以鄂尔多斯市鄂托克旗已处衰退期的不同平茬处理模式的花棒(Hedysarum scoparium)为研究对象,采用根系扫描仪和 WinRHIZO 分析软件定量分析花棒根系的空间分布、形态参数(根长、表面积、体积)、拓扑指数及径级组成等根系构型指标,并结合相关性分析、主成分分析及隶属函数法对花棒不同平茬处理模式进行综合评价。结果表明,不同平茬处理模式(留茬高度0 cm、10 cm、20 cm)对花棒根系构型具有显著影响。留茬10 cm时,根系以倾斜根为主,且根系各形态参数达到最大值,总根长(2 967.11 cm)较未平茬增加79.82%,总表面积(777.63 cm2)较未平茬增加53.42%,总体积(42.61 cm3)较未平茬增加24.34%。拓扑指数在留茬10 cm时最小(0.61),其根系分支更加密集,接近高效的叉状结构。平茬后花棒细根组成显著增多,这可以有效提高植物的资源利用效率。各平茬模式的隶属函数由大到小依次为:留茬10 cm(0.833)、留茬0 cm(0.442)、未平茬(0.259)、留茬20 cm(0.109),因此,留茬10 cm为花棒提质增效、更新复壮的最佳平茬模式。研究结果为西鄂尔多斯地区人工花棒植被抚育管理提供了科学依据。
糖蜜酵母废水脱色菌群发酵条件优化及群落结构解析
穆頔, 单馨, 徐伟慧, 王志刚
陕西师范大学学报(自然科学版). 2026, 54(6): 80-92.  https://doi.org/10.15983/j.cnki.jsnu.2026608
摘要 (   )  PDF全文 (   )   HTML (   )
糖蜜酵母废水(molasses yeast wastewater,MYW)含有大量类黑素、焦糖色素等大分子色素,这些色素的去除是MYW处理的难点。通过对MYW进行长期自然发酵得到原生脱色菌群,利用单因素实验和响应面法对脱色条件进行优化,确定影响脱色率的主要因素为蔗糖浓度、发酵温度及发酵时间。在废水体积分数10%、静置培养、接菌量4%、pH值为10的条件下,额外添加15 g/L蔗糖,43 ℃发酵5 d,可以使废水脱色率达到45.03%,同时能够降低废水中33.72%的化学需氧量(chemical oxygen demand, COD)。此外,该菌群对类黑素、焦糖色素的直接脱色率分别达到25.57%和9.70%。宏基因组测序结果表明,蔗糖的加入改变了脱色菌群的物种组成和相对丰富度,提高了厚壁菌门(Firmicutes)的丰度,富集了乳植杆菌属(Lactiplantibacillus);显著上调了没食子酸脱羧酶编码基因(lpdB、lpdC、lpdD)和糖苷水解酶的表达水平。功能溯源显示,乳植杆菌属是碳水化合物活性酶(CAZymes)的核心贡献者。脱色处理后的MYW对玉米和水稻种子萌发的抑制作用被消除。综上所述,发酵条件优化改变了脱色菌群的物种组成和功能,降低了废水毒性,为糖蜜酵母废水的生物脱色提供了理论依据。
经济动植物生理发育与品质调控
3种植物激素对4种红花油茶花粉萌发及花粉管生长的影响
刘念, 郑涛, 徐皓, 曾海涛
陕西师范大学学报(自然科学版). 2026, 54(6): 93-102.  https://doi.org/10.15983/j.cnki.jsnu.2026609
摘要 (   )  PDF全文 (   )   HTML (   )
为探究不同红花油茶的花粉生物学特性,以浙江红花油茶、粗齿红山茶、西南红山茶和多变性西南红山茶为材料,统计其单花雄蕊数和花粉粒数,并重点分析不同质量浓度赤霉素A3(gibberellin A3,GA3)、萘乙酸(1-naphthaleneacetic acid,NAA)和2, 4-二氯苯氧乙酸(2, 4-dichlorophenoxyaceti acid,2, 4-D)处理对4种红花油茶花粉萌发及花粉管生长的影响。结果表明,在4种红花油茶中,浙江红花油茶的单花雄蕊数和花粉粒数均最高,其次是粗齿红山茶;西南红山茶的单花雄蕊数高于多变性西南红山茶,而单花花粉粒数则相反。适宜不同红花油茶花粉萌发的最佳激素及其质量浓度分别为0.5 mg/L的NAA(浙江红花油茶)、2 mg/L的2, 4-D(粗齿红山茶)、0.5 mg/L的NAA(西南红山茶)、0.5 mg/L的NAA(多变性西南红山茶);诱导花粉管生长的最佳激素处理条件分别为0.5 mg/L的NAA(浙江红花油茶)、2.5 mg/L的2, 4-D(粗齿红山茶)、3 mg/L的2, 4-D(西南红山茶)、3 mg/L的2, 4-D(多变性西南红山茶)。该研究结果为探究不同红花油茶花粉的生理特性及最佳萌发时间和萌发条件提供了数据支撑。
猕猴桃R3-MYB基因家族鉴定
陈舒晴, 王娱乐, 曹磊, 郑浩, 黎蔡禹, 谷园霞, 钟彩虹, 张琼, 张宪智
陕西师范大学学报(自然科学版). 2026, 54(6): 103-113.  https://doi.org/10.15983/j.cnki.jsnu.2026610
摘要 (   )  PDF全文 (   )   HTML (   )
MYB类转录因子是植物中最大的转录因子家族之一,在植物生长发育、代谢、抵御生物和非生物胁迫等多种生理过程中具有关键作用。R3-MYB是MYB家族中的一个亚类,在猕猴桃中缺乏系统研究。通过生物信息学方法从‘东红’猕猴桃中鉴定出167个R3-MYB家族基因,并分析其染色体定位、蛋白理化性质、共线性、启动子顺式作用元件等。结果表明:该家族成员分布于29条染色体,其中23号染色体富集最多,编码蛋白多为亲水性不稳定蛋白,分子量7.9~122.8 kDa;系统进化将其划分为4个亚族,其中亚族Ⅲ与已知花青素抑制因子(拟南芥AtCPC、苹果MdMYB17)聚为同一分支。共线性分析显示猕猴桃与拟南芥的同源性高于水稻,家族扩张主要由片段复制驱动。基因结构呈现高度多样性(编码序列数量1~30个),Motif 2为保守核心基序。启动子分析揭示其富集激素响应(脱落酸和茉莉酸甲酯等)、胁迫应答(低温和干旱等)及光响应元件,蛋白互作网络表明AcR3MYB24处于调控枢纽地位。通过转录组分析与qRT-PCR验证,发现AcR3MYB158和AcR3MYB99在果实发育后期(开花后110~140 d)显著高表达,而AcR3MYB83、AcR3MYB56等基因表达模式与促进花青素积累的转录因子AcMYB10表达趋势一致,推测其可能也具有促进花青素积累的潜在功能。研究首次完成猕猴桃R3-MYB家族的系统鉴定,为解析猕猴桃果实色泽形成的分子机制及品质改良提供了重要基因资源。
佳米驴普通肉块营养品质、食用品质及微观结构研究
万小辉, 张朵朵, 李晨瑞, 王高平, 刘永峰
陕西师范大学学报(自然科学版). 2026, 54(6): 114-125.  https://doi.org/10.15983/j.cnki.jsnu.2026611
摘要 (   )  PDF全文 (   )   HTML (   )
为探究佳米驴普通分割肉块的独特品质,以佳米驴的前腿肉、后腿肉、脖肉和驴腩为材料,以德州驴相对应普通肉块为对照,对比分析驴肉普通肉块的营养品质(水分、蛋白质、脂肪、脂肪酸、氨基酸、矿物质)、食用品质(pH值、色泽、质构、风味)和微观结构的差异。在营养品质方面,佳米驴后腿肉水分质量分数最高(74.46%±0.05%),前腿肉蛋白质质量分数最高(22.79±0.46 g/100 g),驴腩的脂肪质量分数(1.73%±0.43%)、灰分质量分数(5.07±0.30 g/100 g)及钾(235.16±3.11 mg/100 g)、钠(683.57±13.16 mg/100 g)、镁(248.37±8.12 mg/kg)、硒(0.71±0.01 mg/kg)质量分数均最高(p<0.05),脖肉的钙质量分数(174.00±0.01 mg/kg)最高;佳米驴前腿肉的不饱和脂肪酸相对含量最高(71.43%±3.14%),普通肉块必需氨基酸含量在42.57%~43.89%,其中异亮氨酸、亮氨酸和赖氨酸含量较高。在食用品质方面,佳米驴的驴腩L*值显著大于其他部位,显著高于德州驴的驴腩L*值;佳米驴的后腿肉和脖肉a*值显著大于其他部位;佳米驴的驴腩硬度显著小于其他部位,前腿肉的弹性大于其他部位;佳米驴肉和德州驴肉中检测到的挥发性物质种类一致,主要是烷烃、短链烷烃、芳香化合物、醇醛类、硫化物类物质。在微观结构方面,佳米驴的驴腩肌肉聚集程度小于德州驴的驴腩肌肉。综上,佳米驴肉蛋白质含量高、脂肪含量低且不饱和脂肪酸含量高,矿物质丰富,还有良好的色泽、物性和风味,具有较高的食用价值。
