“构建中国特色法学知识体系、话语体系和法治体系”2020年度学术研讨会征稿启事

 

尊敬的           先生/女士：

党的十九大报告提出要“加快构建中国特色哲学社会科学”，“发展中国特色社会主义法治理论”，《中共中央关于全面推进依法治国若干重大问题的决定》提出要“加强法学基础理论研究，形成完善的中国特色社会主义法学理论体系、学科体系、课程体系”的要求。为推动这一时代性问题的深入学术讨论，中国人民大学法学院与《法学家》杂志社以“构建中国特色法学知识体系、话语体系和法治体系”为主题，先后于2018年5月6日、2019年4月21日组织召开年度学术研讨会，精选的一部分会议论文经修改完善后在《法学家》2018年第5期、2018年第6期、2019年第5期、2019年第6期组成专题刊出，产生了良好的学术反响。

2020年适逢中国人民大学法学院70周年院庆，今拟庚续其事，并响应党的十九届四中全会报告提出的“坚持和完善中国特色社会主义法治体系，提高党依法治国、依法执政能力”之号召，再次以“构建中国特色法学知识体系、话语体系和法治体系”为主题，组织召开2020年度学术研讨会，向学界公开征稿。现就有关事项说明如下：

一、时间与地点

本次学术研讨会的召开时间为2020年5月17日（周日）全天，地点为中国人民大学校内（具体地点另行通知）。

二、研讨议题

本次学术研讨会的大主题为“构建中国特色法学知识体系、话语体系和法治体系”。拟投稿参加者可在此大主题之下，自拟具体题目撰文，论文篇幅以1.8－2.2万字之间为宜。

倡导结合法学各个子学科、领域中的具体问题和知识脉络进行言之有物的深入讨论，而非泛泛而谈。本年度研讨会可选择的具体议题包括但不限于：法治体系建设与国家治理体系和治理能力现代化之间的关系；具体法制移植、国外学说引进与法治体系建构的本土性；当代中国法学知识体系与法治体系的具体契合度审视；中国法学知识生产中具体的“特色学说”与“普遍学理”之间的关系；全球化背景下中国法学知识体系、话语体系和法治体系的具体建构。

三、会议费用

本次学术研讨会不收会务费。

凡获主办方正式邀请的京外学者，其在京参会期间的住宿（5月16－17日两晚）和餐食由主办方统一安排并承担费用，往返路费敬请自理。正式受邀的京内学者在参会期间的餐食，由主办方统一安排并承担费用，交通费敬请自理。

四、论文提交

请有意参会的学者在 2020年4月20日前将会议论文投至yuanping@ruc.edu.cn，并以“作者名称＋2020年度学术研讨会投稿”作为邮件标题，以利识别。

投稿论文请采用WORD格式（请勿采用PDF格式），并参照《法学家》的注释体例。

主办方将组织专家对所有投稿论文进行遴选，在2020年5月8日之前通知正式受邀代表，并将从受邀在研讨会上做报告的论文中择优在《法学家》刊登。

五、会议联系人

龚元平（《法学家》杂志社副社长），办公电话：010-62514451，电子邮箱：yuanping@ruc.edu.cn。

 

中国人民大学法学院

《法学家》杂志社

2020年1月16日
