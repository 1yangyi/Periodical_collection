中国民法典解释与适用研讨会征稿启事

十三届全国人大常委会第十五次会议决定，将已经全国人大常委会会议审议的民法典草案提请2020年3月召开的十三届全国人大三次会议审议。如获通过，将意味着中国民法解释时代的大幕即将开启。中国民法典接续了既往立法、实践和法学的诸多智慧，对民法典的解释和适用，就需要以民法典为原点，立足中国社会当前的整体图景，思考未来的可能变迁，揭示民法典的规则发展和价值框架，重思并推进民法典的诸多决断在国家治理体系和治理能力现代化中的意义，着眼民法典规则的解释适用和体系的系统整合，结合立法、实践和法学，融贯规范、价值和思想。

据此，中国法学会民法学研究会、中国人民大学法学院、中国人民大学民商事法律科学研究中心、中国人民大学不动产法研究中心、《法学家》杂志社、《人大法律评论》编辑部拟举办中国民法典解释与适用研讨会，现向学界公开征稿，优秀稿件将在《法学家》《人大法律评论》刊出。现就有关事项说明如下：

 

一、时间与地点

本次学术研讨会的召开时间为2020年3月19-20日，地点为中国人民大学校内（具体地点再另行通知）。

 

二、研讨议题

本次学术研讨会的大主题为“中国民法典解释与适用”。拟投稿参加者可在此大主题之下，自拟题目撰文，篇幅以1.8-2.5万字为宜。倡导结合各分编的具体问题进行言之有物的解释论研究，而非泛泛而谈。

 

三、会议费用

本次学术研讨会不收会务费。受主办方正式邀请的学者在参会期间的餐食，由主办方统一安排并承担费用。

 

四、论文提交

请有意参会的学者在 2020年3月1日之前将论文投至gaolaw68@ruc.edu.cn，并以“作者名称+2020年度民法典研讨会投稿”作为邮件标题，以利识别。

投稿论文请采用WORD格式（请勿采用PDF格式），并参照《法学家》的注释体例（可以暂不采用其中“参见前注”的体例）。

主办方将组织专家对所有投稿论文进行遴选，在2020年3月10日之前通知正式受邀代表，并将从受邀在研讨会上做报告的论文中择优在《法学家》刊登。

 

五、博士生专场

本次会议将专设博士生专场。凡受主办方正式邀请的京外博士生，其往返路费和在京参会期间的住宿（3月18-20日三晚的住宿）和餐食，由主办方统一安排并承担费用。正式受邀的京内博士生在参会期间的餐食，由主办方统一安排并承担费用。主办方将从受邀在研讨会上做报告的论文中择优在《法学家》《人大法律评论》刊登。

 

六、会议联系人

龚元平（《法学家》杂志社副社长），办公电话：010-62514551。

黄尹旭（《人大法律评论》主编），电话：18911412278。

 

主办方：中国法学会民法学研究会

中国人民大学法学院

中国人民大学民商事法律科学研究中心

承办方：中国人民大学不动产法研究中心
