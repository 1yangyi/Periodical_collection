《日本学刊》论文写作规范和注释体例
作者：日本学刊    时间：2015/12/24 14:52:55

一、论文要求

1．问题意识。论文有学术敏感性和问题意识，以基础理论研究为主线，清楚地提出问题，阐述自己的见解，或纠正前人错误、补充他人缺失。有基于科研一线的调查研究基础，及时捕捉本学科内的研究动态以及理论与现实研究热点。

2．创新意识。论文具有一定的前沿性和创新性，在已有的研究领域的知识存量上引入新观点、新方法或新证据。

3．文献综述。遵守学术规范，对所研究问题的理论和现实背景有清楚的描述，简要说明前人的研究成果和目前的研究状况，阐述论文的创新点及理论意义和现实意义。

4．结论基本正确。论文立意新颖、观点鲜明、逻辑清晰、论证严密，结论基本正确。

5．行文规范。一是论文内容规范化，包括提出问题、文献综述、理论推导、经验检验等；二是论文形式规范化，包括文字通顺、结构严谨、注释规范等。

二、论文封面

本刊实行双向匿名审稿制度，这是对"权力的监督和制约"，也是避免"利益相互输送"的一种方式。

1. 论文请加封面，注明论文的中文标题及作者的姓名、工作单位、职称、职务、通讯地址、邮政编码、电话、电子信箱等。可附加学术小传，本刊用于充实和完善审稿专家数据库和日本学刊网"作者阵容"栏目。

2. 正文部分不得出现上述信息，不要出现作者署名及其他有关作者的信息（包括"拙著"等字样），以便匿名评审。

三、内容提要及其他

1. 内容提要的字数在200～300字，用集约性的语句，对论文的核心内容进行客观叙述。主要由论题、观点、方法、结论等要素构成，避免小标题的堆砌和导语、结语的照搬。不要出现"本文"、"笔者"等字样以及注释、缩略语和非明确时间定语。

2. 关键词3～5个，请使用规范、具有专指性的名词或名词性短语。

　　

3. 英文及日文标题、内容提要、关键词。

　　

4. 基金项目（如国家有关部门的基金项目），请注明基金项目和课题的时间、名称与编号。

　　

5. 论文来源做必要的说明，如博士论文、工作论文等。

　　

四、数字

　　

1. 序号：一级标题：一 ; 二 ; 三 ; 、二级标题：（一） ; （二） ;（三）、三级标题：1 ; 2 ; 3 ; 、四级标题：（1） ; （2 ）; （3）;

　

2. 正文、注释：整数一至十一般用汉字表示，阿拉伯数字表示十位以上数字、百分比、分数或日期等。

五、外文

　　

正文尽量少用外文。必须使用时，除人们熟悉的以外，应按《国家通用语言文字法》处理，要有相应的汉译。首次出现时，汉译在前，后括注外文。外国人名的翻译参照商务印书馆2007年出版的《英语姓名译名手册》、《德语姓名译名手册》和《法语姓名译名手册》，并附原文。

　　

专业术语的翻译尽量规范化，在较为生僻或可能引起歧义的情况下请附原文。使用专有名词的缩略形式时，除人们熟悉的（如欧盟、东盟）以外，应先用较详的名称，再用缩略语。
