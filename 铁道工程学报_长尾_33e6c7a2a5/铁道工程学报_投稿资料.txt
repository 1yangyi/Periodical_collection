红层软岩高速铁路路堑上拱变形控制分析
姚裕春, 余雷, 陈明浩, 刘先锋
2026, 43(10): 1-5.
摘要 (  19   )   PDF全文  (  1   )      可视化     收藏
研究目的：红层软岩在我国广泛分布,西南地区是分布最密集区域,我国高速铁路在红层软岩深挖路堑中出现多处长期上拱变形超限的问题,上拱变形量远大于无砟轨道高速铁路的限值4 mm。新建高铁通过红层软岩区需要在既有案例基础上进行总结分析,提出针对性变形控制技术,才能实现红层软岩区高铁路堑长期变形有效控制和高铁平顺、高速运营。
研究结论：(1)以西南红层软岩为典型代表进行红层软岩分区,归纳不同区域红层软岩主要矿物含量和岩石膨胀性;(2)红层软岩路堑上拱变形机理包括开挖卸荷回弹、岩石吸水膨胀及应力调整弹塑性变形,长期蠕变与水岩耦合膨胀作用明显;(3)路堑上拱变形风险主要受路堑特征、岩性特征、膨胀特征三个主要因素控制,给出红层软岩上拱风险评价打分标准;(4)红层软岩路堑应遵循“提前开挖、加强监测、动态设计”原则,根据上拱变形风险评价和变形监测收敛趋势,提出综合采用排水、换填、结构加固和应力释放的控制技术;(5)本研究结果可为红层软岩区新建高速铁路提供有益参考。

任意路堤荷载作用下附加应力的解析式推导
谢百义, 张协崇
2026, 43(10): 6-10.
摘要 (   )   PDF全文  (   )      可视化     收藏
研究目的：针对现有路堤荷载附加应力计算方法存在依赖数值离散近似、计算精度受离散精细程度制约且计算效率较低,以及现有解析解仅适用于梯形断面等规则形状路堤、难以适配边坡平台、非对称路基等复杂多变实际工程断面的问题,为克服数值离散法固有误差与传统解析解适用范围狭窄的缺陷,建立荷载轮廓线与地基应力场之间的直接解析联系,实现任意形状路堤荷载下地基竖向附加应力的精确、高效计算,为铁路路基工程沉降精准预测与稳定性分析提供可靠理论支撑,本文开展任意形状路堤荷载作用下地基竖向附加应力精确解析解法的推导研究。
研究结论：(1)本文以弹性理论布辛内斯克集中力解为基础,经积分推导得到弗拉曼无限长竖直均布线荷载解,以此为理论基石构建解析解推导体系,为任意形状路堤荷载应力计算奠定核心理论依据;(2)将任意多边形轮廓路堤荷载简化为一系列线性荷载段组合模型,基于积分叠加原理严格推导,得到地基中任意点竖向附加应力通用解析公式,有效避免数值离散带来的近似误差;(3)所提解析解具备精确性、高效性与通用性三大优势,无须依赖数值离散细分,计算量不随精度要求改变,可直接通过代数运算求解,且能适配任意多边形断面路堤荷载场景;(4)该解析解已完成编程实现并应用于铁路路基工程实践,后续可推广至公路、大坝等岩土工程领域,为各类线状构筑物的地基应力分析提供参考和借鉴。

注气减饱和与加筋法联合处理液化地基研究
冯义, 田庸子, 陈育民, 谢肖
2026, 43(10): 11-16.
摘要 (   )   PDF全文  (   )      可视化     收藏
研究目的：注气减饱和技术通过向液化土体注气降低地基饱和度实现抗液化,相较于传统加固手段,具有操作简单、绿色经济等优势,此加固手段广受土动力学与岩土地震工程领域学者关注。本文结合长江沿岸可液化砂土区域抗震需求,以沿岸细砂地基为加固对象,通过室内模型及振动台模型试验,开展气体迁移规律、减饱和效果及抗液化特性研究。
研究结论：(1)细砂地基中单点注气存在快速与缓慢两类气体扩散模式,20 cm水平范围内为主要减饱和影响区,注气后地基饱和度降至88%~93%;(2)上部荷载与尼龙网可优化气泡分布形式,12 kPa荷载(等效1.5 m埋深)为减饱和效果分界点,单层10目尼龙网可显著提升减饱和程度;(3)尼龙网能实现水平区域超孔压下降,且减饱和程度与抗液化效果呈正相关,该结论可为细砂地基注气减饱和抗液化加固提供试验依据;(4)细砂地基注气过程中,土体密实度从55%提升至70%时减饱和效果提升但增幅减弱,且密实度越高所需注气压力越大、注气时长越长;(5)4 kPa上部荷载下,注气加10目尼龙网联合加固使细砂地基水平最远15 cm处超孔压比峰值降幅达16.74%,较单纯注气的1.78% 降幅提升显著;(6)本研究成果可为长江沿岸及同类高饱和度细砂地区的浅埋基础设施(如管线、路基、小型构筑物)提供一种经济可行的抗液化加固方案,并为后续现场工程应用与设计参数优化提供试验参考。

单线内燃铁路隧道段选线设计关键技术探究
李巍, 邢存友, 童军, 徐平
2026, 43(10): 17-21.
摘要 (   )   PDF全文  (   )      可视化     收藏
研究目的：铁路内燃机车运行需排放CO、NOx等有害气体,在长大隧道通风不畅的密闭环境内一旦停机或着火,极易导致重大事故。通过系统梳理单线内燃铁路隧道长度,尤其是隧道群长度的关键影响因素,结合理论研究和相关试验数据分析,探究内燃铁路隧道及隧道群长度边界条件。
研究结论：(1)内燃隧道长度主要受运营通风、防灾救援和运输能力耦合作用影响,隧道群长度主要受旅客列车客室空气质量和货车重联后位机车热工参数的影响;(2)从运营通风可靠度考虑,建议隧道长度不宜大于7 km,困难条件下不大于14 km;从防灾救援安全考虑,建议隧道长度不大于着火列车残余运行距离与客车长度的差值;从满足铁路运输能力考虑,建议隧道长度不大于考虑运营通风时间的理论站间距与到发线有效长度的差值;(3)为保证客运列车客室CO2浓度不超标,建议客车在隧道群内运行时间不大于25 min;结合相关重联机车内燃牵引试验,建议多机牵引的货运列车在隧道群内运行时间不大于40 min;(4)本研究成果可为进一步探究内燃铁路隧道及隧道群长度边界条件和选线设计提供借鉴和参考。

高速铁路无砟轨道竖曲线半径优化研究与应用
张高扬, 常逢福, 魏周春, 苏成光
2026, 43(10): 22-26.
摘要 (   )   PDF全文  (   )      可视化     收藏
研究目的：针对高速铁路无砟轨道竖曲线地段垂向加速度评价方法进行分析,确定60 m弦长波高低不平顺与车体垂向加速度之间的对应关系,分析不同竖曲线半径对应的60 m弦长波高低不平顺值,提出不同速度等级下最小竖曲线半径建议值。针对某高速铁路竖曲线地段列车垂向加速度Ⅱ级超限报警问题进行分析研究,提出无砟轨道竖曲线半径优化建议和相应的调整方案,通过现场测试验证竖曲线半径优化方案合理性及实施效果。
研究结论：(1)车体垂向加速度受长波高低不平顺影响较大,60 m弦中点弦测法较300 m弦更能有效反映高速铁路列车动力响应,建议竖曲线地段动力响应分析采用60 m弦中点弦测法管理;(2)由于竖曲线造成的60 m弦长波不平顺值是垂向加速度超限的主要影响因素,设计时应考虑竖曲线地段、大跨度桥梁等特殊地段竖曲线本身矢距对平顺性的影响;(3)根据高速铁路施工和运维技术发展情况,建议按照垂向加速度不超过0.15g的原则控制各速度等级下的最小竖曲线半径;对于设计时速250 km、300 km和350 km高速铁路,竖曲线半径建议分别不小于23 000 m、30 000 m和35 000 m;(4)既有高速铁路采取增大线路竖曲线半径方案进行竖曲线优化调整,调整后车体垂向加速度Ⅱ级超限次数大幅降低,该方案可有效解决列车垂向加速度超限问题,为后续无砟轨道竖曲线半径优化提供借鉴思路。

郭帅杰, 曹祥, 陈金鑫, 贾崔库, 赵晨生
2026, 43(10): 27-31.
摘要 (   )   PDF全文  (   )      可视化     收藏
研究目的：为研究高铁路基不均匀沉降对双块式无砟轨道平顺性影响,考虑混凝土塑性损伤与层间黏结失效特性,建立CRTS Ⅰ型双块式无砟轨道-路基精细化模型,开展静力承载下无砟轨道变形规律研究,分析沉降波长与幅值对轨道变形及轨-基离缝的影响机制,为沉降路基轨道状态评估、沉降管控限值制定以及差异化抬升修复方案选择等提供理论依据。

研究目的：通甬高铁杭州湾跨海铁路大桥是目前世界上距离最长、建设标准最高的高速铁路跨海桥梁,为满足工期等要求,首次在铁路跨海桥中研究并应用装配式桥墩。本文针对装配式桥墩结构形式、节段划分和连接形式,以及预应力筋布置、非对称固定墩受力、自锁式预应力性能、抗震性能及耐久性等技术开展研究,以确定合理技术方案、满足工程建设需求。
研究结论：(1)装配式桥墩采用圆端形空心墩及“下段现浇+上段预制”的装配方案,节段间通过预应力筋实现可靠连接,可满足工期等要求;(2)采用分段式预应力筋布设方式,使预应力筋布置和结构受力大小相匹配;预应力损失中,钢束与管道间摩阻损失及锚具变形、钢束回缩和接缝压密损失较大;随着存墩时间增加,预应力损失值和竖向收缩徐变变形值均有所减少;运营阶段钢束应力比控制张拉力选取;非对称固定墩在摩阻系数0.03、摩擦摆支座摩阻系数0.05时受力最不利,将拼接缝位置调整至21 m高度可满足受力要求;(3)自锁式预应力体系锚固效率系数≥0.95、总应变≥2%,锚固性能和锚下局部受力可靠;计算表明装配式桥墩抗震性能满足要求;(4)通过采用环氧钢筋、加大钢筋保护层厚度和表面涂装等综合措施使装配式桥墩满足海洋环境耐久性要求;(5)本研究结论可为铁路跨海桥梁及装配式桥墩设计提供参考。
