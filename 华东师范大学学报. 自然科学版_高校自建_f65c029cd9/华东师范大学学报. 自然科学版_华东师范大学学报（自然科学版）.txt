陆海统筹视角下我国海岸带自然资源调查监测体系构建与上海实证研究
廖远琴, 郭兴杰
2026 (6): 1-12. doi: 10.3969/j.issn.1000-5641.2026.06.001
摘要 ( 14 )  HTML ( 1 )  PDF(1389KB) ( 8 )
坚持陆海统筹是我国建设海洋强国的核心战略要求, 海岸带作为陆海交互作用最强烈的地理单元, 是落实陆海统筹的关键载体. 我国海岸带地区人口密集、经济发达、生物多样性丰富, 但同时也是人地矛盾最突出、生态环境最脆弱的区域. 本文系统回顾了我国陆域与海域自然资源调查监测的发展历程, 在自然资源统一管理和陆海空间规划深度衔接的背景下, 全面剖析了当前我国海岸带自然资源调查监测体系存在的核心瓶颈. 研究发现, 我国海岸带调查监测存在管理部门协同度不够、空间基准和要素分类迥异、共享共研不足等突出问题. 据此, 本文从统筹协同机制构建、一体化监测站网建设、陆海综合评价体系完善、科技创新赋能、标准法规体系健全5个维度提出了系统性优化建议, 并结合上海独特的河口海岸地理特征与超大城市发展需求开展实证研究, 但跨部门协同的体制壁垒与跨专业研究的协同困境, 是制约未来体系顺利落地的核心障碍.

舟山海域全新世沉积与浅层气特征
姜鑫强, 陈俊兵, 邓兵
2026 (6): 13-22. doi: 10.3969/j.issn.1000-5641.2026.06.002
摘要 ( 10 )  HTML ( 2 )  PDF(2739KB) ( 11 )
利用高分辨率浅地层剖面数据, 结合前人的钻孔资料, 研究了舟山海域全新世地层特征和分布规律, 揭示了舟山海域在长江物质输送与扩散中的作用, 并探讨了在长江沉积物输送减少以及研究区日益加强的海洋工程活动影响下, 沉积环境侵蚀及由此引发的风险. 结果显示, 研究区的地层可分为3个地震单元:全新世浅海相泥质地层、晚更新世滨海相或河流湖沼相砂质地层和基岩. 全新世沉积物较厚区域一般出现在海底平原地形或者水深较大处, 向潮汐通道及岛屿方向减薄甚至完全缺失. 研究区全新世沉积物平均沉积速率在1.25~1.88 m/ka, 小于其北部长江水下三角洲区域的4.5 m/ka以及南部浙闽泥质区的3.5 m/ka. 舟山海域在长江泥沙搬运过程中主要起到输运通道的作用, 而其西北部靠近杭州湾入海口、舟山本岛南部和东北部海底平原部分区域以及朱家尖以东陆架区平均沉积速率在3.1~5 m/ka, 是长江泥沙的局部捕获区. 受泥沙供给减少、海平面上升以及海岸工程建设等因素影响, 未来舟山海域沉积环境可能进一步遭受侵蚀, 值得高度关注. 研究区浅层气顶界面埋深普遍较浅 (0~20 m, 平均约6 m), 近岸区域埋深更小, 增加了气体逸出风险. 浅层气分布受沉积环境控制, 全新世沉积较厚区域气体埋深相对较大. 海底侵蚀与浅层气泄漏之间存在正反馈关系: 侵蚀作用削弱地层封闭性, 促进气体逸出; 而气体泄漏又进一步加剧沉积物侵蚀. 近年来, 舟山海域人类活动 (如港口建设、围垦、油气开发等) 显著改变了水动力条件, 可能影响沉积物输运平衡, 使部分区域由淤积转为侵蚀, 从而加剧浅层气泄漏风险, 影响海底地层稳定性.

长三角区域土地利用/覆盖对碳中和影响的遥感监测与评估研究
韩震, 范震
2026 (6): 23-35. doi: 10.3969/j.issn.1000-5641.2026.06.003
摘要 ( 18 )  HTML ( 1 )  PDF(5188KB) ( 9 )
为精细化评估快速城市化背景下长三角区域碳中和的空间分异规律与驱动机制, 本文基于2005—2022年土地利用/覆盖遥感数据, 构建了耦合碳储量与碳通量的分析框架, 评估了这一时期长三角区域碳中和的时空演变, 并利用LMDI (Logarithmic Mean Divisia Index)模型分解了其驱动因素, 实现了对区域碳代谢静态本底与动态过程的协同观测, 并完成了像元尺度的碳平衡精准诊断与功能分区. 研究表明: 2005—2022年建设用地扩张导致区域碳储量由4881 Tg C降至4790 Tg C, 累计减少1.86%; 碳排放由165.10 Tg C/a增至305.42 Tg C/a, 而净碳汇仅由53.28 Tg C/a增至60.04 Tg C/a, 致使净碳排放量由111.82 Tg C/a扩大至245.38 Tg C/a, 源汇空间错位显著. 长三角区域呈现出“南部固碳、北部排放、过渡承压”的总体格局. 驱动分解显示, 经济规模扩张是碳赤字扩大的首要因素, 而产业结构优化与能效提升则起抑制作用. 本研究为差异化碳管控与国土空间优化提供了科学依据.

大规模海洋生态修复的经济价值与成本效益分析——基于盘锦项目的遥感实证
陈啸, 陈新平, 王楠, 鲍献文, 刘俊良, 解鸿瑞, 安艳红
2026 (6): 36-47. doi: 10.3969/j.issn.1000-5641.2026.06.004
摘要 ( 16 )  HTML ( 2 )  PDF(3995KB) ( 9 )
针对大规模海岸带生态修复成效评估中经济价值量化不足、长期监测难度大的难题, 以盘锦市海洋生态修复项目作为大规模修复的遥感实证, 基于2015年与2023年Sentinel-2遥感影像, 采用随机森林机器学习方法识别土地覆盖类型变化, 结合单位面积价值法量化了修复前后的生态系统服务价值, 并开展2023—2042年成本效益分析. 结果表明, 修复工程驱动养殖池塘与构筑物转为盐地碱蓬等自然生态系统, 盐地碱蓬面积由464.60 hm2增至2687.89 hm2; 生态系统服务总价值从约6.50×108元/a增至约1.46×109元/a, 其中调节服务价值提升最为显著; 累计净收益预计将于2031年由负转正, 证实了生态修复在中长期具有可观的经济效益潜力. 本文构建了一套易于推广的经济价值长效评估技术方法, 为区域乃至全国尺度生态修复的成效评估提供了实证依据与方法参考, 同时为海洋资源管理、防灾减灾能力提升以及决策优化提供有力支撑.

YOLO-MSFR: 基于多尺度特征强化的海洋鱼类关键点检测模型
李丕学, 孟鑫, 顾艳镇
2026 (6): 48-61. doi: 10.3969/j.issn.1000-5641.2026.06.005
摘要 ( 8 )  HTML ( 2 )  PDF(4767KB) ( 6 )
鱼类表型数据的高精度自动化测量是智慧养殖中评估养殖环境、优化养殖策略的重要基础. 针对现有关键点检测模型在水下环境中检测时局部特征提取不足以及多尺度目标检测能力弱的问题, 本文提出了一种改进的YOLO框架——YOLO-MSFR (You Only Look Once with Multiscale Feature Reuse), 引入自适应膨胀率感受野增强模块 (RFEM-AD) 和增强特征融合块 (EFFB), 其中RFEM-AD可缓解浅层特征在提取过程中的细节信息丢失问题, 增强了局部特征的感知能力; EFFB优化通道维度的信息表达, 强化多尺度特征融合的有效性与鲁棒性. 模型在一个高质量水下鱼类关键点检测数据集上进行了测试, 结果表明与已有的YOLO-Pose相比, YOLO-MSFR在平均精度上提升了8.3个百分点, 计算复杂度降低了19.4%, 显著提高了特征增强能力, 能够准确检测鱼体关键点.

长江口咸潮入侵的动力机制、格局演变与研究展望
朱建荣
2026 (6): 62-82. doi: 10.3969/j.issn.1000-5641.2026.06.006
摘要 ( 10 )  HTML ( 1 )  PDF(7644KB) ( 7 )
本文综述长江口咸潮入侵研究方法、动力因子、格局变化及其成因. 长江口咸潮入侵研究方法主要有现场监测、数值模拟和动力分析. 长江口已建有近30个盐度测站, 以实时掌握咸潮入侵的动态、给出咸潮入侵数值预报盐度初始场. 研发和应用的高计算精度咸潮入侵三维数值模式, 在长江口咸潮入侵模拟和定量分析、动力机制的揭示和淡水资源的安全利用中发挥了极为重要的作用. 长江口咸潮入侵受径流量、潮汐、风应力、混合和河势多种因素的综合作用, 还受流域和河口重大工程等人类活动以及气候变化的影响. 径流量在季节尺度上、潮流在半日涨落潮和半月大小潮尺度上影响咸潮入侵. 风对长江口咸潮入侵的影响, 体现在局地风和远程风上. 北风和西北风产生向岸的艾克曼(Ekman)水体输运, 减小北港净分流比, 加剧北港咸潮入侵和北支盐水倒灌. 长江口北支为充分混合型河口, 北港、北槽和南槽拦门沙区域大潮期间为充分混合型河口, 小潮期间为部分混合型河口. 垂向混合增强减小河口环流, 减弱盐分的向陆输运, 导致咸潮入侵距离减小. 长江口河势变化受自然演变和河口重大工程的影响. 河口潮滩圈围、航道疏浚等工程改变局地河势, 影响水动力和咸潮入侵. 北支河势变浅变窄, 导致盐水倒灌显著减弱. 气候变化对长江口咸潮入侵的影响主要体现在海平面上升、流域降水异常引起径流量变化、极端天气事件产生的异常风场等方面. 长江口海平面以大约4 mm/a的速率持续上升, 并有加快趋势, 在百年长时间尺度上对咸潮入侵会有明显加剧影响. 人类活动对长江口咸潮入侵的影响, 主要体现在流域众多大型梯级水库、南水北调工程改变径流量, 以及河口众多重大工程改变局地河势. 2010年后北支盐水倒灌越来越弱, 北港咸潮入侵频次增加, 在持续强北风作用下强度加剧. 目前青草沙水库咸潮入侵主要来源不再是北支盐水倒灌, 而是来自北港正面咸潮入侵, 长江口咸潮入侵格局发生了变化. 河势变化是咸潮入侵格局变化的原因. 本文还对长江口咸潮入侵研究作了展望.

三峡水库蓄水后长江口北支河段河道演变特征
乔红杰, 薛剑锋, 闻卫东
2026 (6): 83-93. doi: 10.3969/j.issn.1000-5641.2026.06.007
摘要 ( 8 )  HTML ( 1 )  PDF(6036KB) ( 9 )
为揭示三峡水库蓄水后长江口北支河段的河道演变特征、驱动机制及演变趋势, 本文基于大通站1950—2023年水沙资料和北支河段1998—2023年实测地形与分流比数据, 系统分析北支河段岸线、深泓线、冲淤格局、口门心滩及汊道分流比的演变规律. 结果表明: 三峡水库蓄水后长江下游径流量小幅变化, 含沙量降幅达70.4%, 但北支持续淤积萎缩与上游水沙条件变化无明显直接关联, 其根本原因在于径潮流动力失衡. 2002年以来落潮分流比大多低于5%, 2023年11月仅为3%, 北支已转变为涨潮主导型汊道. 岸线整治工程使北支边界趋于稳固, 促进口门心滩快速发育; 2011—2023年 –2 m沙体面积、体积分别增长156%、718%, 大幅压缩落潮通道; 1984—2023年北支累计平均淤积厚度2.9 m, 整体呈现“进口淤浅、中段局部冲刷、下段边滩淤积”的冲淤格局. 研究认为, 水动力条件与人类活动是北支河道演变的核心驱动因素, 河道未来将长期维持淤积萎缩态势. 该研究成果为北支河段的综合治理与涉水工程规划提供了科学依据.

近期长江口北支河段深泓摆动与横向稳定性分析
唐风建, 王凯, 沈淇, 霍晓阳, 梅翰林, 董政
2026 (6): 94-106. doi: 10.3969/j.issn.1000-5641.2026.06.008
摘要 ( 8 )  HTML ( 1 )  PDF(2995KB) ( 6 )
长江口北支河势横向稳定性变化直接关乎上海市供水安全、湿地生态保护及航运资源利用. 目前, 尚缺乏对北支河势横向稳定性的最新研究认识. 基于2016—2025年实测地形数据, 结合截面平均宽深比与截面质心宽深比两类横向稳定性指标, 揭示近期北支河势横向稳定性变化特征及初步原因. 研究表明, 近期北支深泓横向摆动显著区域分别位于进口崇头段、上段灵甸港以及中段头兴港. 截面质心宽深比能更好地表征北支河槽横向稳定性变化. 北支进口段崇头与上段灵甸港水域横向稳定性不足, 这分别与流域来水来沙变化下进口江心沙洪枯季冲淤动态调整以及灵甸港局部江心滩体淤涨、发育关系密切; 中段头兴港水域深泓摆动与该河段岸线整治工程有关, 且局部河势横向稳定性仍会受上游在建桥墩工程冲刷影响. 本文成果可为北支河道资源开发与保护提供参考.

基于水平集法的涌流冲击桩基荷载响应及斜桩减载机制研究
潘源, 朱哲皓, 杨冠川
