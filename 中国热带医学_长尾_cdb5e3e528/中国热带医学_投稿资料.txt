青海省玉树州鼠疫疫源地3株鼠疫噬菌体的生物学及基因组学特性
张晓璐, 张鹏辉, 王文龙, 赵海红, 马英, 李伟, 张传宇, 吴海生, 杨建国, 李存香
2026, 26(10): 1383-1390.  https://doi.org/10.13604/j.cnki.46-1064/r.2026-0627
摘要 (  125   ) PDF全文 (  72   )   HTML (  144   )    可视化     收藏
目的 对青海省玉树州喜马拉雅旱獭鼠疫疫源地分离的鼠疫噬菌体117、Y280、Y272进行生物学特性分析，为该鼠疫疫源地鼠疫的防治及防控提供参考依据。方法 以鼠疫疫苗株EV76作为宿主菌，采用双层平板法分离技术，从青海省玉树州鼠疫疫源地167份喜马拉雅旱獭结肠样本中分离出具有代表性的3株鼠疫噬菌体，经纯化处理后进行增殖。通过电镜观察形态，对pH稳定性、热稳定性、紫外线敏感性、裂解谱、一步生长曲线等生物学特性进行检测，利用全基因组测序分析3株噬菌体。结果 鼠疫噬菌体形态学鉴定显示，3株噬菌体均为肌尾噬菌体，可在LB平板上形成0.5~2.5 mm的透亮噬菌斑。生物学特性分析表明，分离的噬菌体均对3株大肠埃希菌具有裂解活性，在60 ℃和pH 5~10范围内比较稳定。紫外线照射30 min内完全失活。全基因组分析结果显示，噬菌体117的基因组总长度为30.68 kb，GC含量为52.9%。Y272的基因组总长度为29.49 kb，GC含量为51.77%。Y280的基因组总长度为28.80 kb，GC含量为51.98%。结论 本研究分离纯化得到3株鼠疫噬菌体，均表现出优异的裂解活性与环境稳定性。在一定程度上间接反映该疫源地生态环境稳定，可为该区域鼠疫流行病学静息期相关基础研究提供参考依据。

云南齐氏姬鼠-大绒鼠鼠疫疫源地常见小型兽类巴尔通体感染调查
杨嘉莉, 杨梅, 杨文庆, 朱春文, 和崇善, 陈怡, 缪宇韩, 高子厚, 浦恩念
2026, 26(10): 1391-1395.  https://doi.org/10.13604/j.cnki.46-1064/r.2026-0139
摘要 (  103   ) PDF全文 (  55   )   HTML (  127   )    可视化     收藏
目的 了解云南省齐氏姬鼠-大绒鼠疫源地常见小型兽类巴尔通体感染状况及其基因特征，为云南省巴尔通体的防控提供依据。方法 于2025年在云南省玉龙县、丽江市古城区、剑川县、鹤庆县采用笼夜法捕获小型兽类，经形态学鉴定后解剖，取其肺、肝、脾等脏器提取DNA，采用普通PCR方法扩增巴尔通体gltA基因片段，对扩增产物阳性样本进行测序，并与GenBank中核苷酸序列进行比对，使用MEGA12.0软件，采用邻接法构建系统进化树，进行系统进化分析。结果 共捕获常见小型兽类1 731只，隶属于3目4科15种，捕获的小型兽类中齐氏姬鼠捕获1 344只（77.64%），是当地的优势种；其次是大绒鼠282只（16.29%）。麝鼩、四川短尾鼩及赤腹松鼠等数量较少。普通PCR检测脏器样本1 731份，巴尔通体阳性118份，总感染率为6.82%。玉龙、古城、鹤庆、剑川感染率分别为4.50%、12.28%、11.05%、2.91%，不同地区小型兽类巴尔通体感染率差异有统计学意义（χ2=38.097，P<0.05）。不同种类小型兽类巴尔通体感染率差异有统计学意义（Fisher确切概率法，P<0.05）。序列比对结果表明，所检出的巴尔通体主要包括两种基因型，分别为Bartonella grahamii以及一种未确定具体种类的巴尔通体。结论 云南省齐氏姬鼠-大绒鼠鼠疫疫源地常见小型兽类存在巴尔通体感染，虽感染率较低，基因型单一，但对人群有致病风险，应加强当地防控监测。

云南省野鼠鼠疫自然疫源地鼠巢蚤群落结构及季节动态研究
詹泽敏, 王剑, 刘正祥, 李玉琼, 李思雨, 曹荣季, 高子厚, 杨梅, 和柏虎, 杨文庆, 和皋, 邵宗体
2026, 26(10): 1396-1402.  https://doi.org/10.13604/j.cnki.46-1064/r.2026-0140
摘要 (  94   ) PDF全文 (  61   )   HTML (  117   )    可视化     收藏
目的 了解云南省野鼠鼠疫自然疫源地鼠巢蚤群落结构及季节性动态情况，为制定鼠疫防控措施提供参考依据。方法 2023—2024年在云南省剑川县和玉龙县历史疫点核心区，选择农耕地生境的地埂，采用挖掘鼠巢的方法，每月开展1次鼠巢蚤监测。将采集的鼠巢及其内容物带回实验室，在瓷盆中检蚤，依据《云南蚤类志》在光学显微镜下进行形态学鉴定与分类计数。计算鼠巢染蚤率、蚤指数、多样性指数、均匀度指数、优势度指数等指标，并采用集中度法和圆形分布法分析鼠巢蚤数量的季节集中趋势和高峰期。结果 共挖掘鼠巢655个，其中染蚤鼠巢95个，染蚤率为14.50%；共检获鼠巢蚤708匹，平均蚤指数为1.08。蚤类隶属于3科6属11种，优势种为高山狭臀蚤（33.47%）、方叶栉眼蚤（33.47%）和特新蚤指名亚种（15.54%）。染蚤率与蚤指数均在1月份达到峰值，分别为32.69%和3.54；8月份未检获蚤类。雌性蚤占比为65.82%，明显高于雄性。集中度法分析显示，M值为0.39，表明鼠巢蚤数量分布存在一定的季节性聚集。圆形分布法分析结果显示，平均角α¯=26.104°，对应高峰日为1月26日，高峰期为11月16日至次年4月8日（Rayleigh检验，Z=19.268，P<0.001）。多样性指数在5月最高（1.458），均匀度指数在1月最高（0.883），优势度指数在6月和9月最高（1.000）。结论 云南省野鼠鼠疫自然疫源地鼠巢蚤群落物种丰富，数量分布具有明显的季节聚集性，蚤指数较高，存在潜在的鼠疫传播风险。建议在蚤类繁殖高峰期前，针对性地开展预防性灭蚤与灭鼠工作，并加强对主要媒介蚤种特新蚤指名亚种的动态监测，以降低鼠疫发生风险。

云南省玉龙、剑川野鼠鼠疫自然疫源地宿主动物3种诱饵诱捕效果评价
李思雨, 邵宗体, 李玉琼, 高子厚, 王剑, 曹荣季, 詹泽敏, 杨梅, 杨文庆, 杨先城, 刘正祥
2026, 26(10): 1403-1408.  https://doi.org/10.13604/j.cnki.46-1064/r.2026-0925
摘要 (  101   ) PDF全文 (  53   )   HTML (  94   )    可视化     收藏
目的 在云南省野鼠鼠疫疫源地筛选适用于监测和诱捕宿主动物的高效、适配诱饵，为该区域鼠疫监测技术优化提供科学依据。方法 2023年4月—2024年3月，使用自制油条、苹果和火腿肠作为监测诱饵，在云南省玉龙纳西族自治县和剑川县设置监测样点，采用笼夜法开展野外诱捕试验，分析3种诱饵的捕获效果。结果 此次试验总捕获率为22.57%（1 687/7 473），3种诱饵均对宿主动物有较好的捕获效果，自制油条、苹果和火腿肠捕获率分别为28.45%（709/2 492）、19.64%（491/2 501）和19.63%（487/2 480），不同诱饵捕获率差异有统计学意义（χ2=73.964，P<0.001）。从月份上看，自制油条月度捕获量为（29.54±11.21）只，捕获效果和稳定性最好；苹果和火腿肠月度捕获量分别（20.45±23.00）只和（20.29±18.50）只，捕获效果相似，但苹果捕获稳定性相对较低。在物种捕获上，姬鼠属对不同诱饵的偏好顺序为自制油条>火腿肠>苹果（χ2=171.506，P<0.001）；绒鼠属对不同诱饵的偏好顺序为苹果>自制油条>火腿肠（χ2=124.435，P<0.001），家鼠属对不同诱饵的偏好顺序是自制油条>火腿肠和苹果（χ2=15.652，P<0.001）；其他鼠种（如白腹鼠属、松鼠、树鼩等）对不同诱饵的偏好顺序为苹果>自制油条和火腿肠（χ2=10.662，P=0.005），上述捕获率差异均有统计学意义（P<0.05）。结论 自制油条与野鼠鼠疫疫源地优势宿主高山姬鼠的食性偏好高度契合，可作为该地区鼠疫宿主监测的优选诱饵；针对特定鼠种，油条可作为姬鼠属和家鼠属的首选诱饵，苹果则适用于绒鼠属、白腹鼠属、松鼠和树鼩等宿主动物；火腿肠的野外诱捕应用价值仍需进一步评估。

云南省江城哈尼族彝族自治县鼠疫疫源地调查
闫可泰, 洪梅, 刘正祥, 李思雨, 段兴德, 杨先城, 徐荣, 胡睿东, 彭春, 魏世强, 邵宗体
2026, 26(10): 1409-1414.  https://doi.org/10.13604/j.cnki.46-1064/r.2026-0975
摘要 (  113   ) PDF全文 (  51   )   HTML (  105   )    可视化     收藏
目的 了解云南省江城哈尼族彝族自治县宿主动物及其体表蚤类的物种构成和数量分布情况，评估当地鼠疫传播风险，为制定针对性防控措施提供数据支持。方法 2025年10月选取江城哈尼族彝族自治县5个乡镇，以农村居民区、农耕地、林地为调查生境，采用夹夜法与笼夜法开展宿主动物调查，收集体表寄生蚤样本，分析宿主动物及其体表寄生蚤的群落结构与空间分布特征。采集人、犬及活体宿主动物血液样本，采用间接血凝试验开展鼠疫F1抗体血清学检测；同时对宿主动物脏器组织样本、寄生蚤样本进行鼠疫菌分离培养。结果 本次调查共捕获宿主动物241只，隶属2目4科9属14种，黄胸鼠为优势种，占比70.12%；白尾稍大麝鼩（9.96%）、黑缘齿鼠（5.81%）、锡金小鼠（4.56%）占比相对较高。农村居民区、农耕地、林地生境宿主动物捕获率分别为3.74%、7.69%、10.97%，不同生境捕获率组间差异有统计学意义（χ2=44.678，P<0.001）。各生境两两比较差异均有统计学意义（均Padj<0.05）。低、中、高海拔梯度捕获率分别为6.26%、7.54%、10.07%，海拔梯度间总体差异有统计学意义（χ2=7.564，P=0.023），仅低海拔与高海拔组间捕获率差异有统计学意义（Padj=0.026）。共检获宿主动物体表寄生蚤4科4属4种，合计43匹，印鼠客蚤为优势蚤种，占74.42%；宿主动物平均染蚤率8.30%，平均体蚤指数0.18。共采集人血清574份、犬血清59份、宿主动物血清47份，鼠疫F1抗体检测结果均为阴性；对241份宿主动物脏器样本及43匹寄生蚤样本开展鼠疫菌分离培养，均未检出鼠疫菌。结论 本次调查显示，江城哈尼族彝族自治县近期鼠疫活动处于低水平，但黄胸鼠和印鼠客蚤优势地位明显，居民区鼠捕获率超过3%。该县地处中缅边境，存在境外病原引入及鼠疫流行风险，应重点强化居民区与边境生境的动态监测，控制宿主密度于阈值以下，为早期预警提供依据。

河北省鼠疫自然疫源地啮齿动物群落智能监测
康东梅, 刘莎, 赵明, 刘晓林, 王威, 闫东, 刘艳华
2026, 26(10): 1415-1420.  https://doi.org/10.13604/j.cnki.46-1064/r.2026-0609
摘要 (  88   ) PDF全文 (  45   )   HTML (  110   )    可视化     收藏
目的 探索智能监测系统在鼠疫自然疫源地啮齿动物群落监测中的应用，为数智防控鼠疫提供科学依据。方法 2024—2025年，在河北省鼠疫自然疫源地康保牧场监测区域内选择6块样地（每年选择3块样地），分别布放鼠害物联网智能监测终端，实时监测啮齿动物群落，定期在鼠害信息网智能监测平台收集数据并进行分析。结果 2024—2025年共监测啮齿动物3科5属8种3 391只次，累计监测1 341 d，平均鼠密度2.53只次/d，其变化趋势为非线性变化（y=-0.078 0x2+0.678 4x+1.486 6，R2=0.396 2）；长爪沙鼠、达乌尔黄鼠为优势鼠种，子午沙鼠和黑线仓鼠为常见种。6块样地啮齿动物物种组成生物量不完全相同，样地A、B、D、E的特有鼠种是长爪沙鼠和子午沙鼠，样地C、F的特有鼠种是达乌尔黄鼠。2024年啮齿动物群落多样性指数H=1.04、均匀度指数J=2.02、优势度D=0.43，春季、夏季、秋季优势鼠种是长爪沙鼠，冬季是子午沙鼠；2025年多样性指数H=1.43、均匀度指数J=2.78、优势度D=0.30，春季、夏季优势鼠种是长爪沙鼠，秋季是黑线仓鼠，冬季是子午沙鼠。24 h鼠种数为3.96±1.36，以1时、2时、24时物种最多，均为6种，长爪沙鼠、子午沙鼠24 h均可以活动，二者活动高峰不同。结论 智能监测系统在自然状态下可以反映啮齿动物群落结构、种群密度、群落多样性及季节变化和活动节律，可作为疫源地智能监测的一种手段，实现数智监测新途径，为鼠疫防控提供重要经验借鉴。

抗逆转录病毒治疗虽能有效控制人类免疫缺陷病毒1型（human immunodeficiency virus-1, HIV-1）复制，却无法彻底清除病毒，根本原因在于HIV-1储存库的长期存在及其异质性。传统的群体水平分析方法受限于分辨率，难以全面揭示病毒储存库的细胞异质性、转录动态及克隆演化特征。本文系统综述单细胞测序技术在HIV-1感染者中应用的三大研究方向：（1）病毒储存库的特征解析;（2）免疫病理机制的深入阐释;（3）新型治疗策略的临床前评估。单细胞RNA测序、单细胞ATAC测序、单细胞VDJ测序和多组学联合分析技术的应用，已成功绘制HIV-1感染者的免疫细胞图谱，鉴定出新的潜伏标志物和免疫调节通路。空间转录组学进一步将研究维度拓展至组织微环境，揭示了中枢神经系统等解剖部位的病毒库特性。同时，单细胞水平的基因编辑评估技术为CRISPR/Cas9抗HIV-1治疗的精准优化提供了关键工具。尽管当前技术仍面临罕见细胞捕获效率、生物信息学定义标准化等挑战，单细胞多组学与功能验证的整合研究将为最终实现HIV-1功能性治愈提供重要的理论依据和技术支撑。

目的 分析石家庄市首例发热伴血小板减少综合征（severe fever with thrombocytopenia syndrome, SFTS）病例感染来源，通过传播媒介调查与重点人群血清学监测分析大别班达病毒（Dabie bandavirus, DBV）传播风险，为SFTS的防控提供经验与依据。方法 对2024年石家庄市首例SFTS病例进行流行病学调查，采集感染来源乡镇及周边乡镇游离蜱与寄生蜱，采用荧光定量PCR方法进行DBV核酸检测；采集平山县2个乡镇常住健康居民血清样本，采用酶联免疫吸附试验进行DBV IgG抗体检测。结果 病例DBV核酸阳性，IgM抗体阳性，病原体高通量测序检出DBV序列7 412条。临床表现主要为发热、血小板与白细胞减少以及腹泻等消化道症状，经治疗后痊愈，无续发病例。该病例有明确野外环境暴露史与疑似蜱虫叮咬史，感染来源为平山县山林地区。2025年共监测到1 380只蜱虫，在寄生蜱中检出DBV核酸阳性的长角血蜱；蜱密度监测发现蜱虫主要活跃于3—5月份，4月份为活跃高峰。共采集300例乡镇居民血样本，DBV IgG抗体阳性10人，阳性率3.33%，不同乡镇环境人群抗体阳性率差异有统计学意义（P<0.05）。结论 石家庄市首例SFTS病例由农村山林地区旅居感染，农村环境中存在蜱虫传播疾病的风险，重点人群存在SFTS既往感染的可能，提示今后应做好媒介生物控制工作，开展健康宣传，提升重点人群防病与就诊意识，加强基层医疗机构疾病识别与诊断能力。

本文报道1例利福平耐药肺结核合并糖尿病患者在抗结核治疗中发生吡嗪酰胺相关性溶血性贫血的诊治过程。患者因咳嗽、咳痰伴发热就诊，当地县医院痰GeneXpert检测示利福平耐药，转入云南省传染病医院后复查结果一致，痰GeneXpert XDR检测示结核分枝杆菌阳性，且对异烟肼、氟喹诺酮类、二线注射类药物（阿米卡星/卡那霉素/卷曲霉素）及乙硫异烟胺敏感。使用短程抗结核治疗方案：[4~6 Am-Mfx-Pto-Cfz-Z-H↑-E/5Mfx-Cfz-Z-E（Am.阿米卡星；Mfx. 莫西沙星；Pto.丙硫异烟胺；Cfz.氯法齐明；Z.吡嗪酰胺；H↑.高剂量异烟肼；E.乙胺丁醇）]治疗1周，血红蛋白从128 g/L降至68 g/L，伴网织红细胞、胆红素、乳酸脱氢酶等升高，且尿潜血阳性、尿胆红素阳性，符合溶血性贫血诊断；停用抗结核药物后血红蛋白恢复，再次入院治疗仍发生贫血，经用药排查明确贫血为吡嗪酰胺所致。本病例提示使用吡嗪酰胺存在诱发溶血性贫血的风险，需严密监测患者的病情变化，及早发现并停药可有效缓解贫血；本报告为基层医疗机构对吡嗪酰胺的罕见不良反应溶血性贫血的早期识别及诊治提供参考依据。
